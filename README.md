# Alice P. — Portfolio

A lightweight static portfolio by Alice P., a student developer at 42 Paris.

## Pages

- Home
- Projects
- About

The site links directly to the public GitHub profile and repositories. There is no contact form and no public email address.

## Local preview

Open `index.html` directly, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating projects

Only change a project status when it reflects the real state of the work. External links use `target="_blank" rel="noopener noreferrer"`.

## Security headers

`_headers` works on compatible static hosts such as Netlify. Other hosting providers may require the same headers in their own configuration format.
