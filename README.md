# Alice P. — Portfolio

A lightweight static portfolio by Alice P., a student developer at 42 Paris.

## Pages

- Home
- Projects
- About

The site links directly to the public GitHub profile and repositories. There is no contact form and no public email address.

## Local preview

Open `index.html` directly, or run a small local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
